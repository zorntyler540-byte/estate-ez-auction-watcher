CTBIDS SALE WATCHER
===================

WHAT IT DOES
------------
Watches your live CTBids sale and shows:
  - Current hammer total
  - Items with bids vs still open
  - Top bids
  - High-bidder USERNAMES (when your boss is signed in)
  - Activity feed + Windows toasts when bids move

This reads the same public sale data the website uses.
Usernames come from bid history, which requires a CTBids login
(the same Sign in your boss already uses on ctbids.com).

FIRST-TIME SETUP
----------------
1. Double-click run_watcher.bat  (installs packages + Chromium once)
   OR manually:
      pip install -r requirements.txt
      playwright install chromium
      python watcher_app.py

HOW TO USE
----------
1. Paste your sale link, e.g.
   https://ctbids.com/estate-sale/46500

2. Click "Sign in to CTBids".
   A Chrome window opens — sign in with the boss account,
   then close that window.

3. Click "Start watching".
   It refreshes on the interval you set (default 45 seconds).

4. Watch the Activity feed and Top bids panel.
   First bids and bid-ups can also pop a Windows notification.

NOTES
-----
- Without sign-in, prices/counts still update; usernames stay blank.
- If usernames stop appearing, sign in again (token expired).
- Be kind to CTBids — don't set refresh below ~15 seconds.
- This is unofficial (not a CTBids-supported API product). It can
  break if they change their site. For your own sale monitoring only.
